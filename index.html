SCALE DECISION — KAPAN DAN BAGAIMANA SCALE
LAYER 3 — SCALE FRAMEWORK (3 Kondisi)
📈 SCALE UP — Volume Lebih Besar
Syarat Scale Up (Semua harus terpenuhi)
✓ ROAS Achieve (gap <10%) selama 1 minggu
✓ Learning phase sudah exit
✓ Spending stabil, tidak ada spike aneh
✓ Tidak ada perubahan lain 7 hari terakhir
Opsi A — Budget Scale
Naikkan Budget
+15–20% setiap kali
Jangan >20% sekaligus
Tunggu 3 hari setelah
setiap kenaikan

Atau: Duplicate campaign
(lebih aman, no reset)
Opsi B — Expand Audience
Scale Out Audience
• Perluas LAL: 1% → 2–3%
• Tambah ATC window lebih luas
  (30 → 60 hari)
• Add upsell/cross-sell adset
• Satu perubahan per minggu
Setelah Scale: Wait & See 7 Hari
Jangan ubah apapun lagi sebelum 7 hari berikutnya
⚖️ MAINTAIN — Jaga Performa
Kondisi Ideal — Maintain Mode
ROAS achieve + volume cukup + spending stabil
Yang perlu dilakukan rutin:
• Refresh creative setiap 10–14 hari
  (untuk hindari ad fatigue)
• Monitor CTR — kalau drop, creative baru
• Monitor audience saturation
• Evaluasi mingguan tetap jalan
• Tambah SKU ke catalog kalau ada produk baru
Tetap evaluasi tiap 7 hari
Kalau stabil terus → pertimbangkan scale up

CREATIVE & AUDIENCE REFRESH — JALAN TERUS SETIAP 2 MINGGU
LAYER 4 — CREATIVE MANAGEMENT & AUDIENCE HEALTH
CREATIVE REFRESH (setiap 10–14 hari)
Trigger ganti creative:
• CTR turun >20% dari rata-rata
• Frequency >5x dalam 7 hari (retargeting)
• ROAS mulai drop meski budget sama

Format rekomendasi:
• Carousel: retargeting SKU spesifik
• Collection: DABA prospecting
• Video (ACV): broad prospecting
• Static: flash promo / event
AUDIENCE HEALTH CHECK (tiap minggu)
Retargeting:
• Audience <5.000? → Perluas window (7 → 14 hari)
• Frequency tinggi → Exclude purchaser lebih agresif
• Saturation? → Tambah SKU ke catalog

Prospecting:
• Refresh LAL dari purchaser terbaru (setiap 30 hari)
• DABA broad → biarkan Meta pilih, jangan filter berlebihan
• Jangan narrow dengan interest/city/age kecuali ada alasan kuat
DATA DELAY — PENTING!
⏱ CPAS Data Delay
  • Data konversi dari Shopee ke Meta: delay 24–48 jam
  • Jangan evaluasi data hari ini → evaluasi data 2 hari lalu
  • Kalau ROAS kelihatan sangat rendah hari ini → cek lagi besok
  • Window evaluasi: ambil data 7 hari, minus 2 hari terakhir
Framework ini hanya bekerja jika dijalankan sebagai aturan, bukan referensi. Evaluasi per 7 hari, satu perubahan per siklus, dan jangan reaktif terhadap data harian.
